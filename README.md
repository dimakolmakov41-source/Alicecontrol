# ALICE CONTROL

Веб-панель для личного управления устройствами и сценариями Яндекс Умного дома.

## Текущий статус

- Интерфейс опубликован через GitHub Pages.
- Пока это UI-прототип: кнопки показывают пояснения и **не отправляют команды колонке**.
- Целевая колонка: Яндекс Станция Лайт, 1-е поколение, голубая.

## Что реально позволяет официальный API

Яндекс документирует API пользовательских приложений для устройств, групп и сценариев умного дома:
- `GET /v1.0/user/info` — список доступных устройств и сценариев;
- `GET /v1.0/devices/{device_id}` — состояние устройства;
- `POST /v1.0/devices/actions` — команды поддерживаемым устройствам;
- `POST /v1.0/scenarios/{scenario_id}/actions` — запуск сценария.

Для него нужны OAuth-разрешения `iot:view` и `iot:control`.

Официальная документация:
- https://yandex.ru/dev/dialogs/smart-home/doc/ru/concepts/platform-protocol
- https://yandex.ru/dev/dialogs/smart-home/doc/ru/concepts/platform-quickstart

## Важные ограничения

Этот API не является API настройки прошивки колонки. Нельзя обещать изменение системного голоса, установку прошивки или доступ ко всем внутренним функциям Станции. Станция Лайт может вообще не отображаться как обычное управляемое устройство в списке API; это нужно проверить после авторизации.

## Что требуется для следующего этапа

1. Зарегистрировать OAuth-приложение Яндекса с доступами `iot:view` и `iot:control`.
2. Проверить доступность API и CORS из браузера.
3. Если браузерный доступ не поддерживается или небезопасен, развернуть небольшой серверный прокси с секретами в серверных переменных окружения. Секреты и токены нельзя коммитить в GitHub.
4. Получить список устройств и сценариев аккаунта и только затем добавлять реальные элементы управления, соответствующие фактическим возможностям устройств.

## Безопасность

Не вводите пароль Яндекса на GitHub Pages и не отправляйте OAuth-токены в чат. Не храните секреты в `index.html`, `script.js` или публичном репозитории.
